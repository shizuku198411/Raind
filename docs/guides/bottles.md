# Bottle Workflows

A Bottle is Raind's local multi-container application unit.

Common commands:

```sh
raind bottle create -f bottle.yaml
raind bottle ls
raind bottle show <bottle-id-or-name>
raind bottle start <bottle-id-or-name>
raind bottle stop <bottle-id-or-name>
raind bottle rm <bottle-id-or-name>
```

For the schema and examples, see [Bottle reference](../reference/resources/bottle.md).
